How to get an admin key
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Tap Generate new token. Name it "Terri website photos" and set it to expire in 1 year.
  3. Under Repository access choose Only select repositories, and pick Terri-leighs-cleaning-services.
  4. Under Permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it above.
